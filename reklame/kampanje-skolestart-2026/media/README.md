# Skjermopptak & skjermbilder — råmedia

Legg de ekte app-opptakene og skjermbildene her. De følger kodene i
[`../06-skjermopptak-shotlist.md`](../06-skjermopptak-shotlist.md).

## Navnekonvensjon

```
SKJERM-<kode>_<format>.<ext>
```

- `<kode>` = koden fra shotlisten, f.eks. `01a`, `02`, `07`.
- `<format>` = sideforhold: `16x9`, `9x16`, `4x5`, `1x1`.
- `<ext>` = `mp4` for video, `png`/`jpg` for stillbilder.

Eksempler:

```
SKJERM-01a_16x9.mp4
SKJERM-01a_9x16.mp4
SKJERM-01b_1x1.png
SKJERM-02_9x16.mp4
SKJERM-07_4x5.png
```

## Personvern

Bruk anonyme/testnavn. Ikke vis ekte elev- eller skolenavn, e-post eller
Feide-detaljer i media som publiseres.
