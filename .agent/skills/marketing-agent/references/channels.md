# Social Media Channel Specifications

## Facebook
- **Goal**: Community building, brand awareness, direct conversions.
- **formats**:
  - **Image Post**: 1200 x 630 px.
  - **Carousel**: 1080 x 1080 px per card.
  - **Story**: 1080 x 1920 px.
- **Copy**: Short, engaging, casual but professional. Use emojis moderately.
- **Ad Types**: Lead Gen, Traffic, Conversion.

## Instagram
- **Goal**: Visual Inspiration, Brand Lifestyle, Product Showcase.
- **Formats**:
  - **Feed**: 1080 x 1080 px (Square) or 1080 x 1350 px (Portrait).
  - **Story**: 1080 x 1920 px.
  - **Reels**: 1080 x 1920 px (Video - 9:16).
- **Copy**: Visual-first. Use "Link in Bio" CTA. Hashtags are key (3-10 relevant ones).

## LinkedIn
- **Goal**: B2B networking, professional authority, recruitment.
- **Formats**:
  - **Image**: 1200 x 627 px.
  - **Document (PDF slider)**: Vertical/Square.
- **Copy**: Professional, value-driven, industry insights. Avoid excessive emojis.

## Twitter / X
- **Goal**: Real-time updates, customer support, trending topics.
- **Formats**:
  - **Image**: 1600 x 900 px.
- **Copy**: Concise (< 280 chars preferred, though 4000 allowed for Premium). Punchy, conversational.

## WebSocket / Email (Newsletter)
- **Goal**: Retention, deep dives, direct sales.
- **Formats**: Responsive HTML email.
- **Copy**: Personalized, detailed, clear CTA.
